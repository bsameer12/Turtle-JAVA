# Turtle Movement Interactive Application (Java Swing)

An Object-Oriented Programming (OOP) interactive visual graphics application built with **Java** and **Java Swing** (`MainClass.java`).

---

## Highlights

- Implements event-driven UI controls and graphical canvas rendering using **Java Swing / AWT**.
- Applies clean OOP principles for modular state and movement command handling.

## Run Locally

```bash
javac MainClass.java
java MainClass
```
